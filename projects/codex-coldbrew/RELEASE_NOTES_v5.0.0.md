# Codex 破甲 · ColdBrew Studio v5.0.0

This is the independent Codex desktop release. It ships a ready-to-run Windows
application and a deterministic complete-source archive as separate assets.

## Download assets

- `Codex-ColdBrew-Studio-v5.0.0-Windows.exe`
- `Codex-ColdBrew-Studio-v5.0.0-Windows.sha256`
- `Codex-ColdBrew-Studio-v5.0.0-Source.zip`
- `Codex-ColdBrew-Studio-v5.0.0-Source.sha256`

Verify the Windows and source downloads against their corresponding checksum
files before running or extracting them.

## What is new

- Codex-specific desktop workbench with task, file, directory and Codex-home
  entry, CLI discovery and launch controls.
- Exact `冷咖啡` activation that renders the complete owner-supplied text without
  omissions. Canonical SHA-256:
  `F7FB45C5DEC0F77E5AFD415DABAACCEEB5B2DDCF1F9918B7B2198BB911F34246`.
- Reversible profile deployment with preview, snapshot, atomic apply, verify and
  guarded restore.
- Local request/review-chain diagnostic fixture covering hit, interrupt, retry,
  recovery, allow and redacted persistent state.
- Actual standby and active product screenshots, a Codex-specific icon and an
  updated responsive project page.
- Expanded fixed-commit source map and an explicit originality boundary.
- Deterministic source ZIP, pinned Windows build and independent CI jobs.

The review-chain fixture is limited to the local application request boundary;
it does not describe a change to a remote service's server-side execution policy.
