# eni-solo v4 架构说明

eni-solo 是石井人格的静态执行骨架，由四块拼成：

| 组件 | 位置 | 职责 |
|---|---|---|
| 全局契约 | `AGENTS.md` | 静态系统指令：人格、输出铁律、路由参考表 |
| 确定性路由器 | `skills/eni-unified-router/scripts/router.py` | 关键词精确匹配，输出工作流回执 |
| 工作流清单 | `manifest/workflows.json` | 每条工作流的有序阶段链 |
| 技能库 | `skills/eni-*/` | 各领域工作流技能（文档 + 脚本） |

执行流程固定：用户输入 → router 命中唯一工作流 → 石井打印
`[石井 ROUTE]` 回执 → 逐阶段打 `[STAGE]` 标记 → 干活 → 验证 → 交付。

设计约束：不设生命周期 hook 之外的隐式环节，不搞插件分发、多 worker
拆分、审批层、共享总线、收敛节点与自动升级循环。路由必须可见，
阶段必须打点，跳过阶段视为执行失败。
