# 石井 CTF single entry

按顺序走一条链：`intake → artifact-preserve → category-route → analyze → reproduce → solve → verify → deliver`。

只有在分类环节需要历史合并索引时才读 `references/challenge-routing.md`。

不要一次装载几十个嵌套挑战技能；选择与题目最接近的现有可执行领域技能即可。
