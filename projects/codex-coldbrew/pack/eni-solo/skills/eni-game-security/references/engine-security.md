# 引擎安全

## Unity 与 IL2CPP

映射托管/原生边界、`global-metadata.dat`、注册表、类/方法索引、对象布局、transform、物理、相机、输入、网络与生命周期方法。用 `$eni-reverse-deep` 与 `$eni-memory-forensics` 验证运行时结构。

关键逻辑用服务端校验保护，而不是依赖混淆。使用构建/版本清单、资产签名、遥测 schema 版本化与一致性检查。

## Unreal

映射 UObject 反射、actor/组件、世界状态、复制、RPC、属性、输入、相机与资产/包边界。审查哪些复制值被信任、哪些动作在服务端验证。

## 通用注意

两个引擎都要记录精确构建标识——偏移与布局变动频繁。检测不要假设单一静态偏移或单一不变的二进制布局。
