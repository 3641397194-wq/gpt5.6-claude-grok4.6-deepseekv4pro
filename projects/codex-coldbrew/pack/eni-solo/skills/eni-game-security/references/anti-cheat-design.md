# 反作弊设计

## 分层控制

1. 关键模拟与经济状态走服务端权威。
2. 服务端校验移动、射速、可见性、归属、库存、冷却与状态迁移。
3. 资产/配置签名并带版本，对局前与对局中校验完整性。
4. 最小化敏感客户端数据，延迟下发暂不需要的信息。
5. 收集可解释遥测，带稳定标识与时间同步。
6. 关联客户端完整性、服务端行为、举报与历史模式。
7. 为高影响动作设计复核与申诉流程。

## 边界纪律

客户端控制可以提高成本、收集证据，但不应成为唯一信任边界。检测要带着预期误报率、置信度、所需样本量与回滚/申诉考量去设计。

## 回归

用已知良性会话与受控异常会话对同一规则集重放测试。
