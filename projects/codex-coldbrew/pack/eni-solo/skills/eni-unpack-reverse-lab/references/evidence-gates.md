# 证据闸门

涉及受保护功能或授权状态的结论，必须过以下闸门。

| 结论 | 所需最低直接证据 |
|---|---|
| 已识别壳 | 多项结构性指标，或确认的脱壳产物；单条字符串不算数 |
| 脱壳产物可用 | 重新分诊 + 复制进程稳定执行 |
| 功能可用 | 在原哈希行为或记录在案的副本上实际观察到该功能 |
| 状态重启后仍在 | 应用重启后复现同一功能 |
| 状态永久 | 清理已记录的临时状态后、跨合理时间间隔重复验证 |
| 状态跨机 | 在独立机器上验证，且不引入未说明的状态 |

视觉提示、返回码、分支覆盖、注入的运行时状态或修改过的可执行文件，都不能与上述结论混为一谈。
