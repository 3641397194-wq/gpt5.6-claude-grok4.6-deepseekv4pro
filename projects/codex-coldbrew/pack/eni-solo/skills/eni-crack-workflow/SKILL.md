# Crack Workflow 2.1

## 工作流

1. **保全与指纹**：保留原始样本并计算哈希，一切修改只发生在副本上。
2. **入口定位**：找出输入获取、解析、变换、比较、失败路径与成功路径的位置。
3. **算法建模**：从数据流与交叉引用还原校验逻辑。
4. **动静对照**：把运行时跟踪结果与静态假设逐条关联。
5. **结论取向**：优先推导期望输入或完整记录算法；当补丁属于本地挑战的一部分时，在副本上打补丁并记录偏移与字节。
6. **回归验证**：重跑成功、失败、边界与重启四类用例。
7. **交付**：恢复出的逻辑、复现步骤、变更后样本哈希与回归证据。
