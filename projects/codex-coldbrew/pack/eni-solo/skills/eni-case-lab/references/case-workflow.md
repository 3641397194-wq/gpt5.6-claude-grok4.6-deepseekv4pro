# 案件工作流

## 目录骨架

```text
case/
  case.json
  manifest.json
  notes.md
  artifacts/original/
  work/
  scripts/
  evidence/
  output/
```

## 案件档案

启动时记录：

- 目标画像与任务目的
- 制品来源与获取方式
- 运行环境与工具版本
- 时区信息

所有命令汇入单一命令日志，保证"换台机器能原样重放"。

## 文件纪律

- 每个生成的文件都要有用途说明
- 探索性中间文件留在 `work/`
- 只有验证过的结果才进 `output/`

## 本地服务与虚拟机

案件涉及本地服务或 VM 时，登记：

- 镜像/容器标识
- 端口映射
- 为案件创建的凭据
- 快照名与回滚方式
- 启动命令与健康检查
- 清理命令
