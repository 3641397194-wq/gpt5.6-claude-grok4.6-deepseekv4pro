# 原生逆向工作流

## 分诊

记录哈希、magic、架构、ABI、字节序、编译器线索、节区/段、导入、导出、重定位、符号、资源、熵、TLS 回调、构造器与缓解措施。

## 执行映射

1. 定位加载器/初始化路径。
2. 识别输入、解析器、分发器、校验、加密、网络、序列化、分配与错误路径。
3. 追踪比较与变换函数的调用方与被调用方。
4. 从重复偏移与访问宽度恢复结构体。
5. 记录函数地址、拟定名称、参数、返回值、副作用与证据。

## 动态分析

使用条件断点、硬件断点、watchpoint、调用跟踪、API hook、syscall 跟踪、堆/分配 hook 与快照。跟踪寄存器/栈/堆数据跨边界流动，而不是逐指令单步。

## 自动化目标

生成签名、枚举/结构定义、解密器、dump 器、补丁器、调试器命令与等价的 C/Python 实现。
