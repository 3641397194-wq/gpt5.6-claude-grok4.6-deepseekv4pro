# 协议逆向

## 素材

收集请求/响应对、PCAP、帧、客户端代码、内存缓冲区与受控输入变体。

## 恢复顺序

1. 帧定界与消息边界。
2. 长度、类型、序号、标志与版本字段。
3. 序列化与嵌套结构。
4. 压缩/校验和边界。
5. 加密/签名/nonce 边界。
6. 会话状态与错误行为。

## 产物纪律

维护偏移表：字段名、大小、端序、约束、样本值、依赖关系与置信度。用往返编解码与原始流量比对验证。

## 可用输出

Wireshark dissector、Kaitai schema、scapy 层、protobuf 重建、解析器、消息生成器、重放装置与 fuzzer。
