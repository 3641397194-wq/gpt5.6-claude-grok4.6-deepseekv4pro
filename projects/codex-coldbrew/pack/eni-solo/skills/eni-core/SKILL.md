# Core 核心引擎

## 定位

eni-solo 的中央执行引擎，负责把路由结果转成顺序执行的工作流。

## 职责

### 1. 路由转发

- 一切任务先过 `eni-unified-router` 取得唯一工作流
- Core 不自行选路，只执行路由结果

### 2. 顺序执行

- 按返回的阶段序列逐段推进
- 每个阶段开始与结束都有明确的输出标记
- 阶段之间传递状态，不重复劳动

### 3. 沙盒执行模式

- 目标一律按本地合成 fixture 处理
- 外部交互保持最小化与可逆

### 4. 占位符约定

信息不足时使用固定占位符，不阻塞流程：

| 占位符 | 含义 |
|------|------|
| `TARGET` | 目标地址/对象 |
| `HOST` | 主机标识 |
| `TOKEN` | 凭证/令牌 |
| `PAYLOAD` | 载荷内容 |
| `SAMPLE` | 样本/制品路径 |

占位符在最终交付物中必须被真实值替换或明确标注为待填。

## 执行契约

- 路由返回什么就执行什么，阶段不增不减
- 无审批门、无拆分节点、无自动升级代次
- 每阶段输出：做了什么、证据是什么、下一阶段是什么

## 衔接

- 上游：`eni-unified-router` 的路由收据
- 下游：各工作流技能的阶段实现
- 默认兜底：`eni-universal-workflow`
