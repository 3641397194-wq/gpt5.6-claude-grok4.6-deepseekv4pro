# 游戏外挂实验室：分析、制作与检测矩阵

## 1. 输入账本

记录目标名称、版本、引擎、平台、架构、网络模型、权威状态位置、样本 SHA-256、靶场启动方式、基线行为、期望修改、验收条件和回滚坐标。

## 2. 信任图

| 区域 | 关键问题 | 证据 |
|---|---|---|
| 输入 | 输入来自硬件、脚本还是回放？ | 事件时序、轨迹、采样率 |
| 客户端状态 | 哪些字段由本地维护？ | 状态快照、写入点、差分 |
| 渲染 | 哪些信息仅用于显示？ | 帧捕获、对象列表、可见性 |
| 存档/配置 | 是否有签名、版本或范围校验？ | 文件哈希、schema、错误日志 |
| 网络/权威 | 哪些状态由服务端决定？ | 请求/响应契约、拒绝路径 |
| 遥测/检测 | 哪些变化能被稳定观测？ | 完整性、行为、时序、相关性 |

## 3. 受控制作闭环

1. 保存只读基线与 SHA-256。
2. 只在新输出文件中改变一个字段或一个行为假设。
3. 生成变更事件：时间、字段、旧值、新值、原因、工具版本。
4. 重放相同输入，比较输出与副作用。
5. 生成验证报告与恢复坐标。

## 4. 检测矩阵

| 变化类型 | 首选检测 | 交叉验证 | 常见误报 |
|---|---|---|---|
| 状态超范围 | schema/range 校验 | 服务端权威重算 | 测试模式、管理命令 |
| 状态锁定 | 时间序列不变性 | 伤害/消耗事件关联 | 暂停、无敌关卡 |
| 速度/时序异常 | 速度与加速度包络 | 输入事件与位置差分 | 高延迟、回放 |
| 配置或资源变化 | 签名/哈希清单 | 加载日志与版本清单 | 合法模组、本地化 |
| 自动化输入 | 轨迹与间隔分布 | 场景难度和目标切换 | 辅助功能设备 |
| 渲染信息泄露 | 最小化客户端数据 | 可见性与对象生命周期 | 观战、回放模式 |

检测标签只是待验证假设；确认需要可重复样本、上下文证据和独立复测。

## 5. 回归门

- 基线可重复生成且哈希稳定。
- 修改后的预期字段全部命中。
- 未声明字段保持不变。
- 检测规则命中受控样本，不命中良性基线。
- 加固后相同修改被拒绝或失效。
- 所有输出均有版本、时间、命令、SHA-256 和回滚坐标。
