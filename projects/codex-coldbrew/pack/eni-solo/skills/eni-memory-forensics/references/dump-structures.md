# 转储、结构体与指针链

## 原始转储处理流程

1. 记录转储来源、地址空间、架构与采集方式。
2. 对文件做哈希并保留原件。
3. 带偏移提取字符串，扫描已知签名。
4. 识别模块/区域，或依据魔数与对齐推断边界。
5. 搜重复值、指针、虚表、对象头与字段模式。

## 结构体还原

关联访问宽度、偏移重复性、邻近值、状态变化与指针目标。产出字段表：偏移、大小、类型假设、样例值与置信度。

## 指针链

验证每一次解引用与所属区域。优先选择以模块/静态对象为根的最短稳定链。记录每一跳是普通指针、句柄、索引、压缩引用还是带标签的值。

## 取证

用 Volatility 3 或 MemProcFS 做进程/模块/句柄/网络/注册表/历史/时间线/注入分析。用 YARA 与区域特征圈定可疑内存，再用映射与行为互相印证。
