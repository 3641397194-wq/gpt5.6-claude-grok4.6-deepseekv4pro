# 逆向流程工作流

## 阶段闸门

### 0. 范围闸门

工件、目标与允许环境明确后放行。范围不清时，先声明假设，继续做离线、非侵入分析。

### 1. 入档交付物

- Case ID 与工作区路径
- 工件清单：SHA-256、SHA-1、MD5、大小、路径、来源说明
- 范围与约束
- 初始问题或假设

### 2. 分析交付物

- 文件类型、架构、编译器/运行时线索、时间戳、签名、壳/混淆特征
- 字符串/配置/导入/导出/符号/资源
- 依赖与运行要求
- 带证据的初始行为假设

### 3. 初始报告交付物

- 执行摘要
- 证据表
- 风险摘要
- 未知项与受阻区域
- 下一步菜单

### 4. 逆向交付物

- 函数/模块图
- 入口点与关键调用图片段
- 数据结构、文件格式、协议、IPC、注册表/文件系统/网络触点
- 可获得的动态追踪

### 5. 深度逆向交付物

- 反编译伪代码解读
- 状态机与算法
- 数据流与信任边界分析
- 适用时的补丁对比/版本比较
- 经验证的行为模型

### 6. 漏洞研判交付物

- 候选弱点清单
- 根因与可达性
- 前置条件与受影响面
- 安全复现证据（崩溃追踪、sanitizer 输出、单元 harness、报文/文件样例说明）
- 严重度论证与修复建议

## 用户可选下一步菜单

按证据定制选项。典型菜单：

1. 继续对最高风险函数/模块做静态逆向。
2. 在隔离实验环境里运行或设计动态追踪。
3. 为跨信任边界的输入建数据流图。
4. 做漏洞向研判与根因分析。
5. 产出可对外分享的精简报告/通报。
6. 停下并汇总当前发现。

## 升级判据

满足任一条件即进入深度逆向：

- 初析发现加壳/混淆代码、自定义加密/编码、未文档化协议、可疑持久化或高风险解析器。
- 观察到崩溃、sanitizer 命中或可疑的边界/状态缺陷。
- 用户要根因、受影响版本、修复建议或厂商式披露材料。
