# 能力覆盖检查表

用这份清单防止漏掉常见逆向技能点。

## 通用技能

- 证据保全、哈希计算、取证链记录
- 文件识别：熵、元数据、签名、时间戳
- 字符串提取：ASCII、UTF-16LE、高熵配置块、URL、路径、注册表键、互斥体、UA、报错文本
- 符号/导入/导出/资源分析
- 控制流与数据流映射
- 假设跟踪与置信度打分
- 附带可复现证据的报告撰写

## 原生二进制

- PE/ELF/Mach-O 头、节区/段、重定位、符号
- 架构与 ABI 识别：x86/x64/ARM/MIPS/RISC-V
- 编译器/运行时指纹：MSVC、GCC/Clang、Go、Rust、Delphi、Nim
- 反汇编/反编译导航、xref、调用图、虚表、RTTI
- 调试、追踪、内存映射、断点/watchpoint
- 壳与混淆：熵、导入解析、脱壳策略、反调试特征

## 托管与脚本运行时

- .NET 元数据、IL、程序集、资源、去混淆特征
- JVM 字节码、Android DEX/APK、manifest、权限、原生库
- Python/Node/PowerShell/Lua 脚本、打包字节码、依赖清单

## 固件与嵌入式

- 容器提取、文件系统切割、bootloader/kernel/rootfs 布局
- CPU/SoC 识别、字节序、内存映射
- init 脚本、服务、Web 端点、硬编码凭据、更新机制
- 无法执行时用仿真或定向静态审查替代

## 移动端

- APK/IPA 结构、manifest/entitlements、权限、URL Scheme
- 网络端点、证书固定特征、本地存储、密钥
- 原生桥接与 JNI/Swift/ObjC 边界

## 文档与解析器

- 文件格式校验、嵌入对象/宏/脚本
- 解析器攻击面、解压/归档嵌套、畸形字段处理
- 送进 GUI 工具前的安全沙箱化与元数据提取

## 漏洞向技能

- 输入面映射
- 信任边界识别
- 边界、整数、生命周期、格式化串、注入、反序列化、认证/授权、加密误用、不安全更新/存储检查
- 崩溃分诊与根因定位
- 补丁对比与回归测试
- 严重度、修复建议与可披露报告
