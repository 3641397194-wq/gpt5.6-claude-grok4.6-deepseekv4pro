# 云与容器安全工作流

## 适用场景

- 云账号、容器集群与 Kubernetes 环境评估
- 镜像、IaC 与配置的合规检查
- 身份与权限路径的审计

## 工作流阶段

### 1. 环境盘点

- 云厂商、账号/项目/订阅、区域
- 集群、节点池、命名空间、工作负载
- 镜像仓库与制品来源
- 身份：用户、角色、ServiceAccount、策略

盘点输出一份"环境地图"，后续所有检查都在地图上定位。

### 2. 分层扫描

| 层 | 方法 | 关注点 |
|---|---|---|
| 云控制面 | Prowler 风格控制项 | 基础配置、合规基准、公网暴露 |
| 镜像与制品 | Trivy 风格扫描 | 已知 CVE、SBOM、密钥残留 |
| IaC 与清单 | 静态检查 | 特权容器、宽泛权限、明文密钥 |
| 集群运行时 | 策略审计 | RBAC、网络策略、准入控制 |

### 3. 攻击路径推演

把扫描发现串成路径：

- 公网入口 → 工作负载 → 元数据端点 → 云身份
- 过宽 RBAC → 逃逸 → 节点 → 其他租户
- CI 身份 → 仓库 → 供应链注入

每条路径标注：已验证环节、推断环节、缺失证据。

### 4. 高影响项人工验证

对高危发现逐条手工复验：

- 权限路径用只读命令实际执行验证
- 配置漂移用两次快照对比确认
- 修复动作先在副本环境演练

### 5. 修复与复扫

- 修复按影响排序：身份收紧优先于配置微调
- 复扫确认修复生效且无回归
- 修复记录绑定复测证据

## 证据要求

- 命令、版本、哈希、证据路径、假设与验证结果全程留痕
- 长跑前持久化检查点
- 云资源快照带账号、区域与时间戳
