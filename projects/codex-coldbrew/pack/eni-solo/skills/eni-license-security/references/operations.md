# 运营与滥用防线

## 生命周期事件账本

跟踪密钥与权益的全生命周期事件：

- 签发来源、经销商/运营方、支付/订单、激活尝试、设备变更、刷新、并发使用、吊销、支持覆盖与迁移；
- IP/ASN/地区、设备可信度、客户端/构建版本、时间戳、nonce/重放标识与错误类别。

## 异常模式检测

- 多设备快速激活；
- 地理上不可能的连续激活；
- 密钥共享与激活突发；
- 反复出现无效前缀；
- 旧客户端回退；
- 刷新风暴；
- 经销商库存异常。

## 管理面防护

- 最小权限；
- 强认证；
- 审计日志；
- 高影响操作审批；
- 导出控制；
- 限定范围的 API 密钥。

## 泄露防线

日志、分析、工单与客户端错误中不得暴露原始许可证密钥材料。

## 事前预案

在事故之前准备好：签名密钥轮换、数据库泄露响应、强制刷新、批量吊销、客户恢复与向后兼容的 schema 迁移。
