# 许可证威胁模型

## 失败类别清单

- 仅客户端的权益判定；
- 内嵌对称/共享密钥；
- 可预测或低熵密钥；
- 未签名或弱签名的许可证文件；
- 可重用的激活响应，缺少 nonce/受众绑定；
- 时钟回拨与过期缓存接受；
- 基于可变或隐私敏感字段的设备指纹；
- 无限激活、共享、转售、凭据填充与并发滥用；
- 暴露密钥有效性或账户状态的详细错误；
- 可补丁的成功分支、可绕过的网络失败与回退模式；
- 恢复旧验证逻辑的更新/降级路径；
- 管理、经销商、支付与支持工作流的滥用。

## 判断基准

- 客户端内放置公开验证密钥是非对称签名的正常做法。
- 客户端内放置私钥或共享验证密钥是严重设计问题。
- 区分"抵抗随意补丁"与"真正的权益安全"：混淆提高分析成本，但不构成可信判定边界。
