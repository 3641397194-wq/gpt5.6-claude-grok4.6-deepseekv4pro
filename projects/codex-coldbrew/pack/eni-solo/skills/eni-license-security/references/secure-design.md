# 安全设计

## 在线优先

权益真相留在服务端。把激活/刷新绑定到产品、账户/密钥、设备记录、版本、受众、nonce、签发时间、过期时间与服务端状态。TLS 之外，仅在消息可移植性或离线验证需要时使用应用层签名。

## 离线许可证

- 使用非对称签名。
- 私钥绝不下发到客户端，客户端只嵌公开验证密钥。
- 签名覆盖规范化载荷：许可证 ID、产品、功能、客户/主体、签发时间、过期时间、可选设备策略、版本与唯一 nonce。
- 时钟回拨用单调/服务端检查点、有限宽限期与明确风险决策处理。
- 离线吊销天然延迟，定义更新/重连要求。

## 设备绑定

- 优先服务端管理的设备记录与可替换设备标识。
- 硬件指纹是噪声信号，不是不可变密钥。
- 支持迁移、维修、隐私与误报处理。

## 生命周期

签发、激活上限、刷新、吊销、转移、密钥轮换、泄露响应、审计日志、经销商控制与 schema/版本迁移要一体设计。
