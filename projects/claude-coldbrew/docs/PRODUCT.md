## Product promise

Claude 破甲 is the ColdBrew desktop product for Claude Code. It gives a
beginner one visible surface for exact activation, user/project scope selection,
preview, deploy, verify, launch and restore.

## Managed brain layers

At user scope the root is `~/.claude`; at project scope it is
`<project>/.claude`. The transaction owns:

1. one marked block in `CLAUDE.md`;
2. seven `rules/claude-pojia/*.md` files;
3. five `skills/coldbrew-*/SKILL.md` files;
4. one `agents/coldbrew-ishii.md` file;
5. two `commands/coldbrew*.md` files;
6. the namespaced state and snapshot directory.

Each file has a first-install baseline, ownership record and deployed hash.
Unmanaged namespace collisions require explicit force after preview. Restore
preserves unrelated text and user-modified managed files.

Ishii is an original ColdBrew task persona, not a claim that Claude model
weights changed. The persona is direct, independent and action-first, with a
fictional background of more than a decade in security, reverse engineering,

but it must not target the user or a group.
