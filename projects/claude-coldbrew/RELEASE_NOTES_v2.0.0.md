# Claude 破甲 · ColdBrew Studio v2.0.0

This release turns the Claude repository into a real, separately packaged
Windows desktop product while retaining the reversible Claude Code deployment
engine introduced in v1.

## Download

- `Claude-ColdBrew-Studio-v2.0.0-Windows.exe` — ready-to-run one-file Windows application.
- `Claude-ColdBrew-Studio-v2.0.0-Windows.sha256` — checksum for the Windows application.
- `Claude-ColdBrew-Studio-v2.0.0-Source.zip` — complete public source, tests,
  build configuration, documentation and visual assets.

## ColdBrew activation

Entering `冷咖啡` opens the complete ColdBrew workspace and renders the fixed
owner-supplied activation contract without omissions. The same contract is
used by the desktop app, the generated Claude rule and the manual pack.

## Product changes

- New `1240×780` desktop workspace with standby and activated modes.
- Client detection, user/project deployment, preview, verify, restore and
  background Claude Code launch controls.
- Target text, file and directory intake inside the activated workspace.
- Real application screenshots on README and Pages rather than concept art.
- Pinned, auditable PyInstaller build and PE/CLI/checksum verification.
- Deterministic source ZIP with internal and repository SHA-256 manifests.
