# [gpt5.6-claude-grok4.6-deepseekv4pro](https://github.com/3641397194-wq/gpt5.6-claude-grok4.6-deepseekv4pro)-glm5.3破甲越狱 Desktop

完整桌面工作台：启动页、指挥台、五档工作档位、五个 BREAK//OPEN 通道、五个模型席位（含 GLM 5.3）、明确目标输入、活动流、结果面板、隔离状态与社群入口。

## 启动

```powershell
npm install
npm start
```

打包 Windows 便携版：

```powershell
npm run pack:win
```

桌面版只处理用户在当前输入框中明确提交的文本。它不会读取本机文件、目录、配置、剪贴板、环境变量或聊天历史。品牌启动词是 `冷咖啡`，控制词是 `BREAK//OPEN`，当前版本为 `2.1.0`。
